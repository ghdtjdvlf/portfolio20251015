Cafe24 브랜드몰 운영 중 타이머·배너·할인바 같은 이커머스 UI를 각 쇼핑몰마다 FTP로 개별 수정해야 하는 비효율을 해소하기 위해, Firebase Hosting 기반의 공용 E-commerce 스크립트 모듈을 직접 설계·구축했습니다.
브랜드별 색상·디바이스 설정은 `data-*` 속성으로 자동 반영되며, `<script>` 한 줄만 삽입하면 모든 쇼핑몰에 동일한 위젯을 즉시 배포할 수 있습니다.

## 프로젝트 개요

기존에는 타이머·배너 등 위젯을 수정할 때마다 운영 중인 브랜드몰 각각에 FTP로 접속해 파일을 개별 배포해야 했습니다.
이 과정을 **Firebase Hosting 기반 중앙화 스크립트**로 전환함으로써, 코드를 한 곳에서만 수정해도 모든 쇼핑몰에 즉시 반영되는 E-commerce 위젯 모듈 시스템을 완성했습니다.

### 주요 기능

- **이커머스 특화 위젯** — 카운트다운 타이머, 프로모션 배너, 배송 타이머, 혜택 할인바
- 브랜드별 컬러·테마 자동 반영 (`data-brand` 속성)
- PC/Mobile 디바이스 분기 UI (`data-device` 속성)
- `<script>` 한 줄 삽입 구조 — FTP 배포 제로화
- 실시간 버전 캐시 무효화 (`?v=timestamp` 방식)
- 위젯별 시뮬레이터 및 코드 뷰어 내장

### 기술 스택

**Frontend**
- HTML5 / CSS3 / JavaScript(ES6)
- 브랜드 컬러 매핑 및 반응형 구조

**Hosting & Delivery**
- Firebase Hosting (`sp-cafe24api.web.app`)
- Script 모듈: `banner.js` · `timer.js` · `ship_timer.js` · `bnf_bar.js`
- 자동 버전 갱신으로 캐시 문제 방지

## 핵심 구현 사항

각 이커머스 위젯을 독립 모듈(section)로 분리하고, `data-brand` · `data-device` 속성 두 개만으로 브랜드·디바이스 환경이 동적으로 적용되도록 설계했습니다.
신규 쇼핑몰 추가 시 아래 스크립트 한 줄을 HTML에 삽입하는 것으로 모든 위젯 배포가 완료됩니다.

```html
<!-- 카운트다운 타이머 위젯 삽입 예시 -->
<script
  src="https://sp-cafe24api.web.app/timer.js"
  data-brand="udit"
  data-device="pc">
</script>
```

```html
<!-- 프로모션 배너 위젯 -->
<script
  src="https://sp-cafe24api.web.app/banner.js"
  data-brand="udit"
  data-device="mobile">
</script>
```
