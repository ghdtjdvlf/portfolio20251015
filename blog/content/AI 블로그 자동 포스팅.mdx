## 프로젝트 개요

주제 하나를 입력하면 **키워드 발굴 → 본문 생성 → 이미지 생성 → 자동 발행**까지 전 과정을 AI가 처리하는 블로그 자동화 플랫폼입니다.

반복적인 블로그 포스팅 작업을 자동화하기 위해 Google Gemini AI와 Playwright를 조합해, 콘텐츠 제작부터 네이버 블로그/카페 발행까지 원스톱으로 처리합니다.

---

## 핵심 기능

### 키워드 헌터
주제를 입력하면 Gemini AI가 SEO 최적화된 키워드 10~20개를 자동으로 발굴합니다. 검색량과 경쟁도를 고려한 키워드 추천으로 노출 효과를 높입니다.

### 병렬 콘텐츠 생성
키워드별로 본문·이미지·썸네일을 **동시에 병렬 생성**해 작업 시간을 대폭 단축합니다. 생성된 결과물은 `output/` 폴더에 구조화해 저장됩니다.

### SEO 자동화
메타데이터, 기획서, 콘텐츠 검수 기능이 내장되어 있어 발행 전 품질을 자동으로 검증합니다.

### 자동 발행
Playwright 기반 자동화로 네이버 블로그와 카페에 자동 로그인 후 포스팅을 발행합니다. 사람이 직접 접속하지 않아도 발행이 완료됩니다.

---

## 기술적 도전

### Playwright 세션 관리
네이버 자동 로그인은 봇 감지 로직을 우회해야 했습니다. 실제 사용자 행동 패턴을 모방하는 딜레이와 마우스 이동을 추가해 안정적인 세션을 유지했습니다.

### 병렬 처리 최적화
여러 키워드를 순차 처리하면 시간이 오래 걸려, `Promise.allSettled`로 병렬 실행하되 API 호출 제한을 초과하지 않도록 청크 단위 제어를 구현했습니다.
