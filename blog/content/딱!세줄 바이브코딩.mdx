## 프로젝트 개요

**PRD 하나 들고 Claude에게 "만들어줘" — 3일 만에 뉴스 앱이 완성됐습니다.**

Liquid News KR은 네이버·다음·구글뉴스와 디시인사이드·에펨코리아·클리앙에서 뉴스를 수집·정제해 모바일에 최적화된 형태로 제공하는 한국 실시간 뉴스 애그리게이터입니다. 직접 코드를 한 줄씩 짜는 대신, **PRD와 CLAUDE.md(룰 파일)를 먼저 작성한 뒤 Claude Code에 위임**하는 방식으로 개발했습니다.

---

## 바이브코딩이란?

> 코드를 직접 작성하는 대신, AI에게 **무엇을 만들지(PRD)**와 **어떻게 만들지(Rule)**를 전달하고 결과물을 받는 개발 방식.

```
PRD 작성 → CLAUDE.md(룰) 정의 → Claude Code 실행 → 버그 수정 → 배포
```

기획 의도와 기술 제약을 문서로 명확히 정리하면, AI는 아키텍처부터 컴포넌트까지 스스로 구성합니다. 개발자는 **디렉터** 역할에 집중합니다.

---

## 핵심 기능

### 🔥 실시간 화제뉴스
네이버·다음 포털의 댓글 많은 뉴스를 수집한 뒤, 디시인사이드·에펨코리아·클리앙의 인기 게시글 키워드와 교차 필터링해 **"지금 한국에서 가장 뜨거운 뉴스"** 를 선별합니다.

### 📰 최신뉴스
경제·사건사고 카테고리의 최신 기사를 3개 포털에서 동시 수집해 통합 제공합니다. 카테고리 탭으로 빠르게 필터링할 수 있습니다.

### 🔍 검색
키워드 입력 시 3개 포털을 동시 검색하고 중복 기사를 클러스터링해 대표 기사 1건으로 노출합니다.

## 기술적 도전 & 해결

### Firebase 배치 캐시 구조
매번 크롤링하면 응답이 느리고 서버 부하가 컸습니다. Netlify Scheduled Functions로 5분마다 배치 크롤링을 실행해 **Firebase Firestore에 결과를 캐싱**하고, API는 캐시를 먼저 반환하는 구조로 응답 속도를 개선했습니다.

```
배치 크롤링 (5분 주기) → Firestore 저장
API 요청 → 캐시 확인 → 신선하면 즉시 반환 / 만료 시 직접 크롤링 폴백
```

### 이미지 프록시
뉴스 썸네일은 외부 도메인 이미지라 `next/image`로 직접 최적화할 수 없었습니다. `/api/image-proxy` 엔드포인트를 만들어 서버에서 이미지를 받아 응답하는 방식으로 해결했습니다.

### 스와이프 탭 전환
`AnimatePresence`로 탭을 언마운트하면 진행 중인 fetch가 취소돼 React Query 캐시가 날아가는 문제가 있었습니다. `display: none` 방식으로 탭을 숨기기만 해 상태를 유지하고, Framer Motion `drag`로 스와이프 제스처를 구현했습니다.

## 바이브코딩 회고

직접 코드를 작성하지 않는다고 해서 기획력이 필요 없는 건 아닙니다. 오히려 **PRD가 모호하면 AI도 모호한 결과물을 냅니다.** 데이터 파이프라인 흐름, 컴포넌트 책임 범위, 애니메이션 규칙 등을 룰 파일에 명확하게 정의했을 때 코드 품질이 눈에 띄게 달라졌습니다.

바이브코딩은 개발 속도를 높이는 도구가 아니라, **명확한 사고를 코드로 빠르게 검증하는 방식**입니다.
