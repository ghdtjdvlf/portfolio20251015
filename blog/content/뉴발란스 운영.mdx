## 프로젝트 개요

뉴발란스 공식 온라인몰 운영 업무를 담당하며, 시즌별 기획전 페이지 제작부터 상품 데이터 연동, 사용자 경험 개선까지 폭넓은 작업을 수행했습니다. 신제품 런칭, 콜라보레이션, 스포츠 이벤트 등 다양한 캠페인을 온라인에서 구현하며 브랜드 아이덴티티를 유지하는 데 집중했습니다.

---

## 담당 업무

### 1. 기획전 제작

시즌 및 이벤트에 맞는 기획전 페이지를 기획·제작했습니다. PC와 모바일 각각의 UX를 고려한 레이아웃 설계와 배너 작업을 진행했습니다.

### 2. 데이터 연동

JSTL을 활용해 상품 데이터를 동적으로 바인딩하고, 기획전 내 상품 노출 조건 및 정렬 로직을 구현했습니다. 재고 상태·할인율·카테고리 필터 등을 서버 데이터와 연동해 실시간 반영되도록 처리했습니다.

### 3. UI/UX 개선

기존 페이지의 레이아웃 개선, 버튼 및 네비게이션 UX 수정, 모바일 대응 작업을 지속적으로 진행했습니다. 사용자 행동 흐름을 분석해 이탈률을 낮추는 방향으로 개선 작업을 수행했습니다.

### 4. 마이페이지 회원정보 수정 버전업

회원 추가정보 수집 프로모션 페이지 신규 제작 및 기존 마이페이지 UI 개선을 진행했습니다. 참여 이력 유무에 따른 케이스 분기, 개인정보 수집 동의 플로우, 맞춤 정보 수정 화면을 PC·모바일 양쪽에 정의하고 구현했습니다.

### 5. 반품 신청 UI 개선

반품 상품 선택 → 사유 선택 → 신청 완료로 이어지는 3단계 플로우 전체를 개선했습니다. 반품 사유 선택 화면에 아코디언 UI를 도입해 가독성을 높였고, PC·모바일 각 화면에서의 일관된 UX를 정의했습니다.

### 6. 상품 세로형 썸네일 레이아웃 정의

기존 정방형 외에 세로형(크롭·여백) 2가지 케이스를 추가 정의했습니다. 어드민(Back Office) 상품 등록·수정부터 FO 상품 목록·상세·검색결과·메인·컬렉션·시크릿 기획전·래플 상세까지 전 화면에 썸네일 처리 방식을 일괄 적용했습니다.

---

## 기술 스택

- **JSP / CSS3** — 시맨틱 마크업, 반응형 레이아웃
- **JavaScript / jQuery** — 인터랙션 및 동적 UI 처리
- **JSTL (JSP Standard Tag Library)** — 서버 데이터 동적 바인딩, 조건부 상품 노출
- **Photoshop / Figma** — UI 레이아웃 설계

## 마치며

단순한 퍼블리싱을 넘어 데이터 연동과 운영 로직까지 다루며 실무에서 요구되는 폭넓은 역량을 쌓을 수 있었습니다. 특히 JSTL을 통한 서버 데이터 바인딩 경험은 프론트엔드와 백엔드의 경계를 이해하는 데 큰 도움이 되었습니다. 반복적인 캠페인 작업을 효율화하기 위해 공통 컴포넌트와 템플릿 구조를 정비한 경험도 이 기간 동안 얻은 중요한 성과 중 하나입니다.
